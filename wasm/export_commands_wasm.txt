From the repository root, build and generate the browser bindings:

cargo build --release --target wasm32-unknown-unknown
wasm-bindgen --target web --out-dir wasm --out-name audiogame target/wasm32-unknown-unknown/release/audiogame.wasm

Serve the `wasm` directory from localhost or HTTPS, then open `index.html`. The browser
will prompt for screen/tab sharing; enable the browser's audio-sharing option to provide
an audio track. Browser support and audio-sharing options vary by operating system.
